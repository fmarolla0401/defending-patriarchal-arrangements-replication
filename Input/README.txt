INPUT
=====

This folder is where the raw survey data must be placed before running
Process/01_Data_Preparation.do. The raw microdata file is NOT redistributed
in this package, because it is subject to the data-use license of its
source archive.

REQUIRED FILE
-------------

File expected here : ZA10000_v2-0-0.dta
Source              : International Social Survey Programme (ISSP) 2022
                       module, "Family and Changing Gender Roles V"
                       (GESIS Data Archive study ZA10000, version 2.0.0)

HOW TO OBTAIN IT
----------------

1. Register for a free account with the GESIS Data Archive
   (https://www.gesis.org/en/gesis-data-archive), or the ISSP's
   designated distribution archive.
2. Locate the ISSP 2022 "Family and Changing Gender Roles V" study and
   download the Stata (.dta) version, v2.0.0.
3. Place the downloaded file in this folder, named exactly
   ZA10000_v2-0-0.dta.

BEFORE SUBMISSION/PUBLICATION: please double-check the exact archive
number, version, and DOI directly on GESIS -- this file reproduces the
identifiers used internally in the do-files and manuscript, but the
authoritative citation should be verified against the archive at the
time of submission.
